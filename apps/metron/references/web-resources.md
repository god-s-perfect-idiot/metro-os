# Metron — web resources

WP8.1 had no first-party manga reader. Metron’s chrome follows official / community
panorama hub captures (Music, People, Photos). Engine lineage is Mihon (Tachiyomi).

## Panorama home

- [Xbox Music on Windows Phone](https://www.windowscentral.com/xbox-music-windows-phone) — hub language
- [People hub (Windows Phone)](https://www.windowsphone.com/) — panorama peeks / contact hub
- Music suite captures in `apps/music/references/web-resources.md`

## Library covers / media grid

- Photos hub album density — `apps/photos/references/`

## Engine (non-WP)

- [Mihon](https://mihon.app/) — upstream reader
- [mihonapp/mihon](https://github.com/mihonapp/mihon) — Apache-2.0 source
