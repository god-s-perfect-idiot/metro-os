## Notes

- Grid is **4 columns only** (Start default density).
- Footprints: **1×1**, **2×2**, **2×4** (2 tall × 4 wide = Start wide).
- Time defaults to **2×4**; Battery defaults to **1×1**.
- Pin-to-Start is out of scope for v1.
